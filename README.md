# YARA AI

Premium Arabic/English WhatsApp conversation summarization platform.

## Current implementation status
- FastAPI service and Champagne Gold dashboard shell.
- Supabase PostgreSQL integration using server-side credentials.
- Group registration and authenticated message-import endpoints.
- Database status endpoint.
- AI summarization and automatic WhatsApp group ingestion are **not yet enabled**.

## WhatsApp limitation
This code does not read ordinary WhatsApp groups automatically. A supported, authorized integration that explicitly provides the required group-message access must be selected and verified first. Do not use unofficial WhatsApp Web session automation or expose QR/session credentials.

## Required Hostless environment variables
Set these in Hostless secrets/environment variables (never commit their values):
- `SUPABASE_URL=https://dzojyfbrlvtadgsfxvql.supabase.co`
- `SUPABASE_SERVICE_ROLE_KEY=<your Supabase service role key>`
- `YARA_APP_TOKEN=<long random secret generated by you>`
- `OPENAI_API_KEY=<optional; summarization is not implemented yet>`

Keep the Supabase service-role key server-side only. Never put it in index.html, a mobile app, screenshots, or GitHub.

## Run
```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```
Hostless command:
```bash
uvicorn main:app --host 0.0.0.0 --port ${PORT:-8000}
```
Container port: 8000.

## Database
The Supabase project must contain `yara_groups`, `yara_messages`, and `yara_summaries` from the initial SQL migration. RLS is enabled and no public policies are created. The backend uses the service-role key, which bypasses RLS; protect it and the API token as secrets.

## Production checklist
1. Configure Hostless secrets.
2. Verify managed database backups and Supabase free-plan inactivity/pause limits.
3. Add authenticated dashboard access and retention/deletion controls.
4. Implement and test a supported WhatsApp group integration.
5. Implement provider-backed Arabic/English summarization and daily/on-demand schedules.
